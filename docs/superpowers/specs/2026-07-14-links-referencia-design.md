# Central de Links de Referência

## Objetivo

Criar uma seção única, categorizada e responsiva que reúna as fontes jurídicas, os formulários, os manuais e os portais oficiais referenciados pelo Calendário Eleitoral. A seção ficará após “Meus Eventos” e antes do rodapé e será acessível por um novo botão “Links de referência” no header.

## Navegação

- Adicionar ao header um terceiro botão de navegação rápida, ao lado de “Meus Eventos”, com o texto “Links de referência”.
- O botão chamará a função de rolagem suave já usada pelo header e terá como destino `#links-referencia`.
- Em telas estreitas, os três botões poderão quebrar linha sem rolagem horizontal.
- A seção será renderizada em `App.tsx` imediatamente após `MeusEventos` e antes do rodapé.

## Apresentação aprovada

O layout aprovado é “Cards por categoria”:

- duas colunas no desktop e uma coluna no mobile;
- cabeçalho com ícone, título e texto explicativo;
- um card para cada categoria, com título, ícone e contagem;
- links apresentados em linhas simples, sem descrição secundária;
- cada título curto será o próprio hiperlink;
- cada link exibirá indicação visual de abertura externa;
- sem busca, filtros ou categorias recolhíveis nesta primeira versão.

## Arquitetura de dados

Criar `src/data/linksReferencia.ts` como fonte central da seção. O módulo deverá expor:

- o tipo `CategoriaLinkReferencia`;
- a interface `LinkReferencia`, com `id`, `titulo`, `url` e `categoria`;
- metadados das cinco categorias, incluindo título, ícone e ordem;
- a coleção imutável com as 28 referências;
- uma função de consulta por `id` para componentes que reutilizem links fixos.

Os links fixos do header e do rodapé deverão consumir o catálogo em vez de repetir URLs literais. Os links Markdown das observações continuarão legíveis dentro de `eventos.ts`, mas serão cobertos por uma verificação de integridade.

## Componentes

- Criar `src/components/links-referencia/LinksReferencia.tsx` para renderizar exclusivamente a seção.
- Atualizar `src/components/layout/Header.tsx` com o botão e o ícone `Link2`.
- Atualizar `src/components/layout/Footer.tsx` para obter as resoluções pelo catálogo central.
- Atualizar `src/App.tsx` para posicionar a nova seção.

## Regra de integridade

Todo novo link externo adicionado a um evento, a uma observação ou a um componente informativo deverá ser simultaneamente cadastrado em `src/data/linksReferencia.ts`, exceto links expressamente classificados como créditos pessoais, como o Instagram do autor.

Uma verificação automatizada deverá:

1. extrair URLs Markdown das observações de `eventos.ts`;
2. coletar URLs não vazias de `fundamentacao`;
3. confirmar que cada URL informativa está presente no catálogo;
4. rejeitar IDs ou URLs duplicados no catálogo;
5. confirmar as 28 referências e as contagens por categoria.

## Acessibilidade, responsividade e segurança

- Mobile-first, com validação inicial em 375 px.
- Títulos longos devem quebrar linha sem provocar rolagem horizontal.
- Links devem possuir foco visível e nome acessível completo.
- Todos os destinos externos abrirão em nova aba com `target="_blank"` e `rel="noopener noreferrer"`.
- A seção usará elementos semânticos `section`, `article`, `ul` e `a`.
